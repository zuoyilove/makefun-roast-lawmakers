One satirical sentence roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF: the program writes the sentence to `/output/entry.txt`.

> The same lawmakers who want to write the rules for AI, crypto, and the entire internet still forward a Word document to an intern with the subject line 'please make PDF'.

## Run it

```sh
python3 main.py
```
